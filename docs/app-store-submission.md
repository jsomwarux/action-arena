# App Store Submission Metadata

## App Name
Action Arena: Fantasy Picks

## Subtitle
Fantasy Sports Prediction Leagues

## Description
Action Arena is a free-to-play fantasy sports prediction game for friends and leagues. Join or create a league, make weekly sports picks, compete in head-to-head matchups, and climb season standings. No real money is wagered. Free to play.

Build a weekly lineup from NFL games, including straight picks, parlays, and point-boost teaser picks. Every player gets the same virtual coin budget each week, and standings are based on virtual coin results, matchup scores, and season-long performance.

Commissioners can run private or public leagues, track weekly matchups, view pick history, and celebrate season awards. Arena Coins are a virtual cosmetic currency only and have no monetary value.

Action Arena is built for the fantasy sports category. League prizes, if any, are arranged outside the app by league commissioners.
