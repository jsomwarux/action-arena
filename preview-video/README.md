# Action Arena — App Store Preview Video

A 30-second App Store preview video, built with [Remotion](https://remotion.dev).
Output spec follows Apple's iOS App Preview requirements:
**1080×1920 (vertical) · H.264 MP4 · 30 fps · ≤30 s · <500 MB.**

Deliverable: `out/action-arena-preview-v1.mp4`

## Commands

```bash
npm install          # one-time
npm run gen:audio    # regenerate both audio assets (synth hit + music bed)
npm run render       # gen audio -> Remotion render -> finalize -> deliverable
npm run studio       # interactive preview / scrubbing
```

`npm run render` runs: (1) regenerate `public/synth-hit.wav` + `public/music-bed.wav`,
(2) Remotion render to `out/_raw.mp4`, (3) `scripts/finalize.mjs` trims + remuxes
to the compliant final. See **Constraints** for why step 3 exists.

## Composition (frame map @ 30 fps, 900 frames)

| Frames | Time | Scene |
|---|---|---|
| 0–30 | 0:00–0:01 | Cold open — real app icon fades in on black |
| 30–90 | 0:01–0:03 | Title card — "SETTLE IT / IN THE ARENA." (headline only) |
| 90–195 | 0:03–0:06.5 | Build your lineup (`pick_board.png`, Ken Burns 1.0→1.12, green budget pulse) |
| 195–315 | 0:06.5–0:10.5 | Designate your lock (`lineup.png`, gold badge pulse, **0:08 detail cut**) |
| 315–435 | 0:10.5–0:14.5 | Beat your friends (`leaderboard.png`, user-row pulse) |
| 435–585 | 0:14.5–0:19.5 | **The moment** — Score Burst, +148, synth hit (5 s) |
| 585–810 | 0:19.5–0:27 | Brand close — app icon + tagline + FREE TO PLAY (music outro) |
| 810–900 | 0:27–0:30 | Compliance card → fade to black |

Cuts are hard except: cold-open fade-in, final fade-to-black, the 0:08 Lock
**detail insert** (500 ms close-up on the gold "1.5× Multiplier" badge), and a
300 ms **flash-to-white** into the celebration (`FlashWhite`).

## Audio

Two layers, mixed by Remotion, both pre-rendered (no runtime/network deps):

- `scripts/gen-synth-hit.mjs` → `synth-hit.wav` — chromatic-split major stab
  (L/R detuned ±9 cents), **−12 dBFS**, fires once at the burst (0:14.5).
- `scripts/gen-music-bed.mjs` → `music-bed.wav` — 105 BPM A-minor sports/trap
  bed, **−18 dBFS**, 0:01–0:27. Builds through the mechanic shots, **half-time
  drop** at the celebration so the hit punches through; clean 0:27–0:30
  compliance. (A minor is harmonically compatible with the C-major hit.)

Layers sum to ≈ −10.8 dBFS at the burst overlap (hit-dominant, no clipping).

## The celebration (`src/components/ScoreBurst.tsx`)

A faithful DOM port of the app's `WinCelebration` Score Burst variant
(`components/cosmetics/index.tsx`). The RN original animates via `Animated.timing`
on a wall-clock loop, which doesn't advance under Remotion's deterministic
renderer; this port keeps the exact layout / colours / six shard positions /
digit tiles / easing but drives everything off `useCurrentFrame()`, re-timed to
peak at ~1.5 s then hold for the 5 s scene. Digits read `+148` (app uses `+100`).

## Assets (`public/`)

- `icon.png` — the shipped iOS app icon (`assets/images/icon.png`), used literally
  in the cold open / brand close / compliance card.
- `pick_board.png`, `lineup.png`, `leaderboard.png` — real app captures
  (1320×2868), recovered from git history.
- `synth-hit.wav`, `music-bed.wav` — generated by the scripts above.

## Constraints / gotcha

Remotion pads the AAC track to the full composition length, and AAC priming then
pushes the **container** ~59 ms past 30.0 s, which App Store Connect rejects.
Audio content ends by 0:27, so `scripts/finalize.mjs` trims the track to 29 s
(keeps all audio, stays <30 s) and adds `+faststart`, letting the exact 30.000 s
video govern the container. Verify:

```bash
ffprobe -v error -show_entries format=duration,size out/action-arena-preview-v1.mp4
```

Fonts (Bebas Neue + Inter) load via `@remotion/google-fonts`. Bebas Neue is a
single-weight family; heavier weights faux-bold in Chrome.
